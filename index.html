Golf Shack Audit Page

This page controls transaction audit records, bank receipt confirmation and seller fund release. Sign in with a real Golf Shack admin account — every action here is tied to the admin's own email.

Only emails on the Golf Shack admin list can open this page. Ask an existing admin to add your email if you get "not an admin" after signing in.

SARS compliance register

Admin transaction control centre.

Track buying, selling, money received in the Golf Shack account, buyer delivery confirmation, VAT fields, proof references and Admin release of seller funds.

Company / tax settings

Complete these before live trading so exported reports carry the correct company, SARS and VAT details.

5-year retention: export and retain transaction records, invoices, proof of payment, payout approvals and supporting documents for SARS audit readiness.
Sequential audit trail: every order receives a unique GSTX number and records every status change with timestamp and Admin action.
VAT field separation: item price, delivery, Golf Shack service fee, fee VAT, total receipt and seller payout are split for accountant review.
Release control: seller funds can only be released after money is marked as visible in the Golf Shack account and buyer delivery is confirmed.

Transaction audit register

Admin can confirm funds, mark shipping, release seller funds, hold/dispute, export or print the register.
